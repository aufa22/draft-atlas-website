Data provenance & quality

Di balik angka.

Sumber: respons API Liquipedia milik pengguna, diolah 8 Oktober 2026. Website ini berisi data tersimpan dan tidak mengambil pembaruan otomatis.

  • Unit analisis adalah satu game, bukan satu seri BO3/BO5. Game tanpa hasil, notplayed, dan draft bermasalah tidak masuk statistik utama.
  • Game valid memiliki pemenang, 10 pick dan 10 ban terisi serta unik, tanpa hero yang dipick sekaligus diban, dan sisi blue/red yang valid.
  • Pick rate = pick ÷ game valid. Ban rate = ban ÷ game valid. Presence = game hero dipick atau diban ÷ game valid. Win rate = win ÷ pick; kosong jika tidak ada pick.
  • Pencarian dan minimum pick menyaring daftar hero, bukan jumlah game pembagi. Filter tahap menghitung ulang statistik dari game pada tahap itu.
  • Hanya hero yang teramati pada draft valid ditampilkan. Hero yang tidak pernah muncul belum dapat dinyatakan tidak eligible.
  • Nilai patch API seragam per musim: S16 1.9.99, S17 2.1.61, S18 2.1.95. Nilai tersebut belum diverifikasi ke patch pertandingan; jangan menganggapnya histori patch yang lengkap.
  • Statistik ini belum memiliki label buff/nerf/adjust dan tidak menunjukkan kepastian keputusan balancing.
Acuan: S16 · S17 · S18. Statistik utama dapat berbeda dari sumber karena pengecualian game bermasalah.
